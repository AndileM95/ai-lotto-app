# AI Lotto Smart App

A Python application that analyses historical lottery results and generates number combinations using statistical analysis and a weighted selection method.

## Features
- Historical lottery draw analysis
- Number frequency statistics
- Tracking draws since a number last appeared
- Weighted lottery number combination generation
- Statistical summaries of historical data

## Technologies
- Python
- Pandas
- Statistical analysis

## Project Files
- `app.py` — Main application
- `lotto_data.csv` — Historical lottery data
- `.gitignore` — Excludes unnecessary files from Git

## How to Run
1. Install Python.
2. Install Pandas using `python -m pip install pandas`.
3. Open the project folder in VS Code.
4. Run `python app.py` in the terminal.

## Disclaimer
This project is for educational and statistical exploration purposes only. Lottery draws are random and independent. Historical results cannot predict or guarantee future winning numbers.
